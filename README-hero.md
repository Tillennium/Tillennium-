# Hero backdrop (optional)

- `hero-bg.jpg`: high-impact institutional image (trading floor, terminal wall, port or city skyline). It is shown behind the hero at low opacity and faded toward the bottom. Dark, low-detail images work best. Remove the file and the signal tape alone is shown.
- Video loop: set `heroVideo` (and optionally `heroVideoPoster`) in `config.js`, for example `hero-loop.mp4`. Use a muted, subtle loop under about 3 MB. It is skipped for visitors who prefer reduced motion or have data saver on.
